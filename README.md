# 🩺 AuraHealth AI — Clinical Intelligence Engine

> **Your 24/7 AI-Powered Virtual Health Operator & Disease Intelligence Portal.**

**AuraHealth AI** is a state-of-the-art web application engineered to bridge the gap between complex medical data and human-centric access. Built with an ultra-sleek **Liquid Glass / Glassmorphism UI**, AuraHealth provides instant access to comprehensive disease records, nutritional deficiency profiles, and an interactive **AI Symptom Cross-Examiner** that analyzes symptom patterns in real time.

---

## ⚡ Key Capabilities

* **🤖 Interactive AI Symptom Operator**: Powered by live AI integration, users can describe complex physical symptoms and receive structured potential diagnoses, clinical indicators, and urgency advice.
* **📚 Comprehensive Disease & Deficiency Library**: Instant search and categorization across Cardiovascular, Respiratory, Neurological, Metabolic, and Nutritional Deficiency conditions.
* **💧 Liquid Glass Aesthetic**: Translucent interfaces, dynamic ambient light glows, backdrops with real-time blur (`backdrop-blur-xl`), and micro-interactions optimized for touch and desktop.
* **♿ Fluid Accessibility**: Fully responsive architecture equipped with text scaling controls (`A`, `A+`, `A++`) and high-contrast mode toggle.
* **🚨 Emergency Safety Rails**: Built-in red-flag detection system highlighting critical warning symptoms directing users immediately to emergency care.

---

## 🛠️ Built With

* **Frontend Framework**: React 18 + Vite
* **Styling**: Tailwind CSS
* **Icons**: Lucide React
* **AI Engine**: Google Gemini API Integration
